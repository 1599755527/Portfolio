# English Portfolio

English portfolio website for Dennis Fei. Includes checked English project documents, spreadsheets and diagrams.

## Build and publish

Install dependencies with pnpm, then run `pnpm build`. The static site is exported to `out/`, configured for `/Portfolio` on GitHub Pages.

Only Omen videos are included as compressed web copies; original local videos are unchanged. Other projects retain their existing externally hosted video links, with no video uploads to this repository.

The GitHub Actions workflow publishes the static export. Enable GitHub Pages with GitHub Actions as the source in repository settings.
